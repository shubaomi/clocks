# 时间造物集：史实、映射与边界

这份文档把“历史上确有的时间知识或仪器”和“本站为数字时钟设计的当代映射”分开。作品使用中国风或世界星空的视觉语言表现同一个本地时间，并不主张时间归属于某个国家。

## 史实依据

- **十二时辰与干支**：香港天文台说明十天干与十二地支组成六十干支循环，古代月份与时辰以地支命名。[Heavenly Stems and Earthly Branches](https://www.hko.gov.hk/en/gts/time/stemsandbranches.htm)
- **二十四节气**：节气源于对太阳周年运动的观察；黄道被分为二十四个相差 15° 的位置。[UNESCO](https://ich.unesco.org/en/RL/the-twenty-four-solar-terms-knowledge-in-china-of-time-and-practices-developed-through-observation-of-the-suns-annual-motion-00647)、[香港天文台](https://www.hko.gov.hk/sc/gts/time/24solarterms.htm)
- **八卦与六十四卦**：《系辞》记述刚柔相摩、八卦相荡，八卦互相重叠形成六十四卦。[Chinese Text Project](https://ctext.org/book-of-changes/xi-ci-shang)
- **四象二十八宿**：四象各领七宿，二十八宿位于黄道与月道附近，是日月行星经过的天区。[香港太空馆](https://hk.space.museum/en/web/spm/resources/teachers-corner/constellations-and-myths/glossary-of-chinese-star-regions-asterisms-and-star-names.html)
- **日晷与漏壶**：中国国家博物馆藏汉代日晷资料说明，当时漏壶因水压变化可能产生误差，日晷可用于校正。[中国国家博物馆](https://www.chnmuseum.cn/zp/zpml/kgfjp/202110/t20211029_251999.shtml)
- **香钟**：粉末香沿预量路径燃烧，不同模板代表不同长度的时间；香钟在中国兼具实用、宗教与休闲用途。[Science Museum Group](https://collection.sciencemuseumgroup.org.uk/objects/co729/chinese-incense-clock)
- **黄道十二宫**：十二宫是以春分点为起点的十二个等分黄道区段；岁差使今日观测星座与古代黄经对应产生偏移。[香港天文台](https://www.hko.gov.hk/sc/gts/time/24solarterms.htm#zodiac)
- **水运仪象台**：苏颂、韩公廉设计的北宋天文钟以水力连接上层浑仪、中层浑象、下层动力与报时机构，木人按刻与时报告时间。[中国科学技术馆](https://www.cstm.org.cn/cszl/hxzg/kxts/art/2020/art_01a44715ea68496f920de7c033043b3d.html)、[国立自然科学博物馆](https://www.nmns.edu.tw/en/exhibitions/galleries/human-cultures-hall/water-powered/)
- **古代天文仪器**：北京古观象台现陈列浑仪、日晷、圭表等仪器；本站只借用其结构语言，不复制具体藏品。[北京市人民政府](https://www.beijing.gov.cn/renwen/rwzyd/bwg/bjggxt/202301/t20230112_2897556.html)
- **现代星座边界**：IAU 将 constellation 定义为有坐标边界的天区，和历史星点图形、asterism 并非同一概念。[International Astronomical Union](https://www.iau.org/Iau/Iau/Science/What-we-do/The-Constellations.aspx)

## 本站的当代时间映射

| 作品 | 页面映射 | 性质与限制 |
| --- | --- | --- |
| 十二时辰 | 24 小时分成十二个两小时区间 | 历史名称配现代本地民用时间 |
| 十二生肖时辰印谱 | 十二生肖各值守两小时 | 视觉创作，不是传统生肖计时法 |
| 一日四时·二十四节气 | 一节气一小时，一候二十分钟 | 把一年压缩为一天；另显示按太阳黄经估算的真实节气 |
| 太极昼夜 | 日进度推动阴阳明暗比例 | 哲思可视化，不是历史仪器 |
| 易时·六十四卦 | 一日等分 64 段，每段 22 分 30 秒 | 二进制式时间编码，不作占卜 |
| 铜壶滴漏 | 水滴记秒，浮箭以一天进度上升 | 受水视觉是数字模型，不模拟真实流体和水压 |
| 四象二十八宿 | 星盘随一日旋转，月相按日期近似 | 不具可靠宿界数据，因此不宣称“当前精确宿位” |
| 十二星座·黄道天穹 | 日期决定太阳黄经区段，时刻推动天穹 | 展示等分黄道宫，不作运势或现代 IAU 星座边界判断 |
| 圭表日晷 | 时刻决定影向，年进度近似影长 | 未使用经纬度与太阳高度，只是民用时间的数字重构 |
| 香篆流时 | 完整香路压缩为一天 | 灰、烬、香分别表示过去、当下、未来 |
| 水运仪象台 | 秒驱动步进，分钟转动天球，刻与整点报时 | 结构意译，不是历史机械复原图；默认无声 |
| 六十甲子 | 一秒一干支，一分钟走完一周 | 明确是现代压缩编码，不是传统逐秒纪时 |

## 中英文术语与作品说明

- 十二时辰 — **Twelve Shichen / Twelve Double Hours**；地支 — **Earthly Branches**。两小时区间沿用现代钟点边界显示。
- 十二生肖时辰印谱 — **Zodiac Seal Almanac**；“值守两小时”是本站创作，不是古代制度。
- 二十四节气 — **Twenty-Four Solar Terms**；七十二候 — **Seventy-Two Pentads**。候是传统物候意象，不是访客所在地的实时天气。
- 太极昼夜 — **Taiji Day and Night**；阴/阳 — **yin / yang**。面积按本地民用时间连续变化。
- 六十四卦 — **Sixty-Four Hexagrams**；爻 — **line / yao**；八卦 — **Eight Trigrams**。页面使用由下至上的六位二进制状态和伏羲式组合逻辑；卦名只作编号识别。
- 铜壶滴漏 — **Bronze Clepsydra**；浮箭 — **indicator float**。四壶结构是历史机制的图形概括，水位不是工程级流体模拟。
- 四象 — **Four Symbols**；二十八宿 — **Twenty-Eight Mansions**。页面仅给出旋转天盘和近似月相，不输出当前精确宿位。
- 黄道十二宫 — **twelve zodiac sectors**；星座边界 — **constellation boundaries**。本站太阳位置对应等分黄经区段，并不等同 IAU 不等宽天区。
- 圭表 — **gnomon**；日晷 — **sundial**。影长、影向均是无定位的数字重构。
- 香篆钟 — **incense seal clock**；余烬 — **ember**。一天被压缩为一条完整香路。
- 水运仪象台 — **water-powered armillary sphere and celestial globe tower**；浑仪 — **armillary sphere**；浑象 — **celestial globe**。页面是功能分层意译，不是复原图。
- 六十甲子 — **Sexagenary Cycle**；天干 — **Heavenly Stems**；地支 — **Earthly Branches**。第 0 秒甲子，第 59 秒癸亥。

## 计算说明

- 所有动态作品默认读取浏览器本地民用时间；不读取定位，也不向外发送数据。
- “真实节气”使用简化太阳黄经公式，足以用于展览提示，但不能代替历书级天文数据。
- 月相使用朔望月平均长度 29.530588853 日的近似模型。
- 日晷没有地点、真太阳时与均时差校正，因此画面会主动标注为“数字重构”。
- 二十四节气、六十四卦、六十甲子等“一日/一分钟压缩”均是本站创作规则，界面与说明必须持续明确标注。

## 设计原则

1. 先让它是一座能读出当下的时钟，再让文化成为读时方式。
2. 每座作品使用不同空间语法，不复用同一圆盘换皮。
3. 过去、当下、未来至少以位置、明暗、痕迹或运动中的一种明确区分。
4. 中英文解释保持短小；完整边界留在本页，不让展品变成说明书。
